# ⚙️ Патч 2.0.12

![Патч 2.0.12](/assets/news/patch.png)

*Данный патч включает в себя все исправления внедрённые на сервер с 07.07 по 19.07*

## 📝 Список изменений и нововведений:

- Теперь у колоды карт в описании предмета показывается содержимое колоды

![Содержимое колоды карт](/assets/news/card_description.jpg)

- Внедрён новый экспериментальный протокол, который в теории может вызвать прирост TPS. Просим вас сообщить, стало ли комфортнее играть, а также сообщить нам, если вы столкнётесь с новыми странными багами или проблемами со входом на сервер.

---

## ⚙️ Исправлены баги:

- Исправлено отображение кнопок временных заданий. Теперь корректно отображается надпись о возможности забрать награду
- Теперь корректно отображается уведомление о прогрессе и об успешном выполнении коллективного задания
- Теперь при выполнении коллективного задания в чат будет отправляться уведомление о выполнении достижения
- Исправлена ошибка, связанная с возможностью получить прогресс по коллективному заданию, когда задание уже было выполнено
- Исправлена жёлтая коробка испытаний, теперь коробки второго и третьего уровня полностью проходимы
- Исправлено несколько багов, связанных с досрочным выбрасыванием игрока с арены
- Пластинку "Отскок" теперь можно найти в вагонетках с сундуком в заброшенных шахтах в биоме серных пещер
- Исправлен баг, при котором описание предметов из готовки переносилось на другие предметы в инвентаре
- Исправлен баг, из-за которого при ломании контейнеров из готовки они не выпадали
- Исправлен баг, при котором не выдавались предметы, купленные через блок магазина
